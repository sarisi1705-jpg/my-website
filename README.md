# SSPS Product Catalog

واجهة عربية تجريبية لشركة **SSPS — حلول لأنظمة الحلول والطباعة**.

## ماذا تحتوي النسخة الأولى؟

- واجهة RTL متجاوبة للموبايل والكمبيوتر.
- كتالوج تجريبي من 16 منتجاً.
- بحث فوري حسب الاسم والموديل والعلامة التجارية.
- فلترة حسب التصنيف والعلامة التجارية.
- لوحة تفاصيل لكل منتج.
- شعار نصي وأيقونة أصلية مؤقتة، من دون استخدام شعار الشركة الحالي.

## تشغيل المشروع

يتطلب Node.js 22 أو أحدث وpnpm.

```bash
pnpm install
pnpm dev
```

ثم افتح الرابط المحلي الذي يظهر في الطرفية.

## أين أعدّل المحتوى؟

- المنتجات التجريبية والواجهة: `app/page.tsx`
- الألوان والتصميم المتجاوب: `app/globals.css`
- عنوان الموقع ووصفه: `app/layout.tsx`
- أيقونة الموقع: `public/favicon.svg`

## الخطوة التالية المقترحة

فصل بيانات المنتجات في ملف مستقل، ثم إنشاء مستودع Git وربطه مع GitHub قبل إضافة البيانات الحقيقية.
